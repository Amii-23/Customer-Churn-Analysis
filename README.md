# Telecom Customer Churn Analysis

## Project Overview

This project analyzes telecom customer data to identify key factors influencing customer churn and retention. The analysis focuses on customer demographics, contract types, tenure, payment methods, internet services, monthly charges, and additional services.

## Tools and Technologies

- Python – Data cleaning and preprocessing
- SQL – Data analysis and customer segmentation
- Power BI – Interactive dashboard and data visualization

## Dataset

The dataset contains 7,043 customer records and includes information related to:

- Customer demographics
- Contract type
- Customer tenure
- Payment methods
- Internet services
- Monthly and total charges
- Additional services
- Customer churn

## Analysis Performed

- Overall churn rate analysis
- Churn by contract type
- Churn by customer tenure
- Churn by payment method
- Churn by internet service
- Churn by monthly charges
- Churn by customer demographics
- Churn by additional services
- High-risk customer identification
- Contract and internet service analysis

## Key Findings

- Overall churn rate: 26.54%
- Total churned customers: 1,869
- Month-to-month customers showed higher churn
- Customers with shorter tenure were more likely to churn
- Payment method and internet service influenced churn patterns
- High-risk customer segments were identified for customer retention strategies

## Dashboard
